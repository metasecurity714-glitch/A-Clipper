# REELS CLIPPER

Native Android-first AI short-form video clipping studio.

**Caption languages locked for v1:** English, Hindi, Hinglish and Odia.

## Current implementation (v0.1.0 foundation)

- Native Kotlin + Jetpack Compose + Material 3 app.
- Android system video picker (no broad storage permission required).
- Local video preview using AndroidX Media3 ExoPlayer.
- YouTube URL field with clear source/rights messaging.
- Dark creator-focused interface.
- GitHub Actions APK build workflow.

## Important status

This is the first runnable Android foundation, not yet the complete AI clipping pipeline. The “Start AI Clipping” action currently validates the selected source and reports the next pipeline step. Automatic transcription, highlight extraction, emoji timing, face tracking, editing and final MP4 export are planned implementation stages and are not falsely presented as complete.

## Requirements

- Android Studio or AndroidIDE with JDK 17.
- Android SDK 35.
- Gradle wrapper generated by Android Studio/AndroidIDE (see below).

## Open and build

1. Download and extract the repository.
2. Open the `REELS-CLIPPER` folder in Android Studio or AndroidIDE.
3. Let Gradle sync.
4. Build > Build APK(s), or run:

   ```bash
   gradle assembleDebug
   ```

5. APK output: `app/build/outputs/apk/debug/app-debug.apk`.

If your IDE asks to create a Gradle wrapper, accept it. The wrapper is intentionally not committed in this starter archive.

## YouTube source policy

The app does not download arbitrary YouTube videos or bypass platform restrictions. A URL may be retained for reference/metadata; video editing requires a local video file that the user owns or is authorized to process. Use official export/download options where available.

## Planned architecture

- Android: Media3 playback/Transformer, ML Kit face detection, Room project history, MediaStore export.
- AI service (optional): FastAPI + faster-whisper for word timestamps, language detection and clip suggestions.
- Caption renderer: timed word segments, template styles, emoji suggestions and burn-in rendering.
- Hybrid mode: local editing and lightweight detection; optional cloud transcription/highlight enhancement.

## Caption language strategy

- English and Hindi: multilingual speech recognition.
- Hinglish: Hindi-English code-switching; preserve Latin/Roman words when appropriate and provide a manual correction editor.
- Odia: multilingual transcription with explicit language selection/fallback and manual correction.
- Word-level timestamps and language-specific punctuation are required before claiming captions are “perfect”.
